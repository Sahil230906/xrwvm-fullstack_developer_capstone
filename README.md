# Best Cars Dealership Application

## Repository Name
xrwvm-fullstack_developer_capstone

## Project Name
Best Cars Dealership Full Stack Application

## Project Description
This project is part of the IBM Full Stack Application Development Capstone Project.
It is a full-stack car dealership application built with Django, React, Node.js,
Express, MongoDB and Docker. Users can browse dealerships, view dealer details,
and read and submit reviews.
